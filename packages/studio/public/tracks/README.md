# tracks/

Your own music for the Beat Path examples goes here (WAV, MP3, M4A, OGG or FLAC). The examples' tracks are generated in the browser by the in-repo drum synth; to replace one, put the file here and set its `file` in `packages/studio/src/beat-path/tracks.ts` (for example `file: "tracks/my-track.wav"`). Nothing in this folder is bundled by default.
