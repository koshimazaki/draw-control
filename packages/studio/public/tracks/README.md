# tracks/

Your own music for the Draw Control examples goes here (WAV, MP3, M4A, OGG or FLAC). Example 1 plays `neon-rain-loop.mp3` from here: the owner's track (glitchcandies, made with Suno), used with permission, his cut of "Neon Rain, Empty Streets" (38.28–51.77 s, six bars from a kick at about 107.5 BPM, a seamless 13.488 s loop, not time-stretched). Examples 2 to 4 generate their tracks in the browser with the in-repo drum synth; to replace one, put the file here and set its `file` in `packages/studio/src/beat-path/tracks.ts` (for example `file: "tracks/my-track.wav"`). Everything in this folder is copied into the build.
